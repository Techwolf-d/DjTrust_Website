# Videos Folder for D.J. Trust React Web

Put all your video files (`.mp4`, `.webm`) in this folder or its subfolders:
- `public\videos\hero\` — Background hero banner videos
- `public\videos\events\` — Event & showcase videos

### Usage in React:
```tsx
<video 
  src="/videos/hero/my-video.mp4" 
  autoPlay 
  loop 
  muted 
  playsInline 
  className="w-full h-full object-cover"
/>
```
